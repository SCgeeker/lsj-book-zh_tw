## 📊 核心教材資源整合

### Zhang等人(2024)研究數據資源

**論文基本資訊：**
- **標題**: "Watching Hands Move Enhances Learning From Concrete and Dynamic Visualizations"
- **作者**: Icy (Yunyi) Zhang, Alice Xu, Ji Y. Son, James W. Stigler
- **數據來源**: 153名心理統計學課程學生的實驗數據

**可用教學資源：**
1. **實驗設計資料**: 三組對比實驗設計 (n=47, n=52, n=51)
2. **測量工具**: 完整的前測(5題)和後測(33題)題本
3. **真實數據**: 作者承諾提供的實驗二與實驗三rawdata Excel檔案
4. **研究情境**: 大學生學習R語言shuffle()函數的真實教學情境

### 教材整合的優勢

**真實性**: 來自實際心理學實驗的原始數據，非模擬數據
**完整性**: 包含實驗設計、測量工具、結果數據的完整研究循環
**相關性**: 統計教學情境，直接對應jamovi使用場景
**標準化**: 經過同儕審查的研究工具，具備信效度保證

## 🎯 具體單元整合示例

### Unit 8: Hypothesis Testing - 使用Zhang研究數據

**教學設計架構：**

#### 8.1 真實研究情境導入
```markdown
### 基於真實心理學實驗的假設檢定學習

**研究背景介紹：**
「我們將使用Zhang等人(2024)在UCLA進行的真實教學實驗數據。這個研究比較了三種不同的統計教學影片對學生學習效果的影響。」

**數據集特徵：**
- 樣本大小：153名心理統計學課程學生
- 實驗設計：隨機分派到三個教學條件
- 測量工具：標準化的前後測評估
- 研究變數：教學條件、前測分數、後測分數、視覺回憶等

**學習目標：**
1. 使用真實數據學習jamovi中的假設檢定功能
2. 理解實驗設計的統計分析邏輯
3. 掌握ANCOVA和事後比較的操作和解釋
4. 培養基於證據的統計推論能力
```

#### 8.2 jamovi操作實務
```markdown
### 使用jamovi分析Zhang研究數據

**步驟一：數據載入與檢視**
- 匯入作者提供的rawdata Excel檔案
- 檢視變數類型和數據結構
- 進行基本的數據清理和檢查

**步驟二：描述性統計分析**
- 計算三組的基本統計量（M, SD, N）
- 製作分組的描述統計表格
- 建立視覺化圖表（箱形圖、小提琴圖）

**步驟三：推論統計分析**
- 執行控制前測的ANCOVA分析
- 進行Bonferroni多重比較校正
- 計算和解釋效應量（偏eta平方）

**步驟四：結果解釋與報告**
- 按APA格式報告統計結果
- 解釋統計顯著性的實務意義
- 討論研究發現的限制和推廣性
```

#### 8.3 批判性思考與反思
```markdown
### 基於真實數據的統計思維培養

**統計假設檢驗：**
1. 零假設：三種教學方法的效果相等
2. 對立假設：至少一種方法效果不同
3. 顯著性水準：α = .05
4. 統計檢定力：基於樣本大小的評估

**結果解釋的謹慎性：**
- 統計顯著性 ≠ 實務重要性
- 相關性 ≠ 因果性
- 樣本特徵對推廣性的影響
- 研究設計對結論的限制

**延伸思考問題：**
1. 如果在不同的學生群體中重複這個研究，結果會如何？
2. 這個研究的發現如何應用到實際的統計教學中？
3. 還需要什麼額外的證據來支持研究結論？
```
