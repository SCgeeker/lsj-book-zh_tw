## 🔄 基於AI Fluency v1.5的架構升級

### AI Fluency 4D核心能力整合

基於最新的AI Fluency Framework v1.5 (2025年1月)，我們將4D核心能力完全整合到jamovi教學設計中：

#### 1. **Delegation (委託)** - 創意願景與AI工具選擇
- **教學應用**：學生學會選擇適合的統計分析工具和AI輔助方式
- **jamovi整合**：引導學生理解何時使用jamovi的自動化功能，何時需要手動操作

#### 2. **Description (描述)** - 明確溝通與指令制定  
- **教學應用**：培養學生準確描述統計問題和分析需求的能力
- **jamovi整合**：學會如何清楚表達統計分析的目標和期望結果

#### 3. **Discernment (辨識)** - 批判性評估與品質判斷
- **教學應用**：發展學生評估統計結果品質和解釋適當性的能力
- **jamovi整合**：學會識別jamovi輸出結果的品質和可信度

#### 4. **Diligence (盡責)** - 負責任使用與倫理考量
- **教學應用**：培養負責任的統計實務和透明的研究報告能力
- **jamovi整合**：確保統計分析和報告的倫理性和透明度

## 🎯 AI輔助提示語模板開發框架

### 基於4D架構的提示語設計原則

#### **階段一：DELEGATION（委託階段）- 學習目標設定與工具選擇**

```markdown
## jamovi統計學習委託提示語模板

### 學習目標委託
「我希望使用jamovi和AI協助來學習統計概念。我的具體目標是[具體目標]，我的統計基礎程度是[初級/中級/進階]，我希望重點關注[具體統計概念或方法]。

請協助我：
1. 評估jamovi是否適合我的學習目標
2. 建議最適合的AI協助方式
3. 設計個人化的學習路徑」

### 工具選擇委託  
「面對[具體統計問題]，我需要在jamovi中選擇合適的分析方法。請基於我的數據特徵[描述數據]和研究問題[具體問題]，建議最適合的統計分析選項。」
```

#### **階段二：DESCRIPTION（描述階段）- 問題明確化與需求表達**

```markdown
## jamovi問題描述提示語模板

### 統計問題描述
「我的研究問題是[具體問題]。我的數據包含[變數描述]，樣本大小為[N]。我希望透過統計分析來[具體目標]。

請協助我：
1. 將研究問題轉化為統計假設
2. 識別最適合的統計檢定方法
3. 在jamovi中找到對應的分析選項」

### jamovi操作需求描述
「我想在jamovi中執行[具體分析]。我的數據格式是[描述]，我預期的輸出結果包括[具體需求]。請提供詳細的操作步驟和設定建議。」
```

#### **階段三：DISCERNMENT（辨識階段）- 結果評估與品質檢核**

```markdown
## jamovi結果辨識提示語模板

### 統計結果品質評估
「我在jamovi中得到以下統計結果[貼上結果]。請協助我評估：
1. 這些結果在統計上是否合理？
2. 效應量是否具有實務意義？
3. 是否有違反統計假設的跡象？
4. 結果解釋是否適當？」

### jamovi輸出解讀
「基於jamovi的輸出結果，請協助我：
1. 識別最重要的統計指標
2. 評估統計顯著性的實務意義  
3. 檢視是否需要後續分析
4. 判斷結論的可信度」
```

#### **階段四：DILIGENCE（盡責階段）- 負責任使用與透明報告**

```markdown
## jamovi負責任使用提示語模板

### 倫理使用確認
「在我的統計分析過程中，請協助確認：
1. 我的分析方法是否符合研究倫理？
2. AI協助的範圍應該如何適當揭露？
3. 統計結果的限制和不確定性如何表達？
4. 需要進行哪些額外的驗證？」

### 透明度報告
「基於我使用jamovi和AI進行的統計分析，請協助我撰寫透明度聲明，包括：
1. AI協助的具體範圍和方式
2. 統計分析的假設和限制
3. 數據處理和分析的完整流程
4. 結果解釋的責任歸屬」
```

## 🔬 基於實證數據的單元強化設計

### Unit整合示例（以Unit 8: Hypothesis Testing為例）

**原有設計基礎：**
- 科學法庭模擬
- 假設檢定邏輯劇場
- 統計顯著性理解

**基於論文appendix的強化：**
```markdown
### 實證數據整合假設檢定教學

**真實研究案例應用：**
「讓我們使用來自實際心理學實驗的數據來學習假設檢定。這個數據來自[論文標題]的實驗二，研究問題是[具體問題]。

**Step 1: 委託階段 - 分析目標設定**
- 使用jamovi分析實驗二的rawdata
- 設定具體的統計假設
- 選擇適當的檢定方法

**Step 2: 描述階段 - 問題明確化**
- 描述實驗設計和變數
- 明確假設檢定的邏輯
- 設定jamovi分析參數

**Step 3: 辨識階段 - 結果評估**
- 評估jamovi輸出的合理性
- 判斷統計顯著性的意義
- 比較與原論文結果的一致性

**Step 4: 盡責階段 - 負責任解釋**  
- 承認分析的限制
- 透明報告AI協助範圍
- 確保結論的適當性」
```
