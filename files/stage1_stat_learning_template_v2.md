### Unit 1: 為什麼要學習統計學？


🎯 Unit 1學習目標
- 理解統計學在科學研究中的核心作用
- 建立統計思維和科學素養
- 認識心理學研究中統計方法的應用
- 培養對資料和證據的批判態度

**1.1 統計學的科學角色 [LSJ Ch.1]**

**什麼是統計學？**
統計學不只是數字計算，而是一套科學思維方法，幫助我們：
- 從不確定性中找出模式
- 區分真實效果與隨機變異
- 做出基於證據的推論
- 評估研究發現的可信度

**生活中的統計思維：**
想像您看到新聞報導："研究發現聽古典音樂能提高智商"
統計思維會問：
- 這個研究如何設計的？
- 樣本大小夠大嗎？
- 有控制其他可能影響因素嗎？
- 效果大小有實際意義嗎？
- 結果能重複驗證嗎？

**1.2 心理學中的統計應用**

**為什麼心理學特別需要統計學？**
心理學研究的挑戰：
- 人類行為的複雜性和變異性
- 無法直接觀察的心理歷程
- 個體差異的巨大影響
- 測量誤差的不可避免

**統計學如何解決這些挑戰：**
- 描述和量化心理現象
- 控制無關變項的影響
- 從樣本推論到母群體
- 檢驗理論假設的正確性

**實例：Zhang研究的統計邏輯**
Zhang等人想知道不同教學影片是否影響學習效果：
1. **問題**：手部動作是否促進學習？
2. **假設**：有手部動作的影片會有更好的學習效果
3. **設計**：隨機分配學生到不同影片組別
4. **測量**：學習成績和判斷準確性
5. **分析**：比較各組的平均表現
6. **結論**：基於統計證據支持或反駁假設

**1.3 統計素養的重要性**

**作為消費者的統計素養：**
能夠批判性地評估：
- 新聞中的統計報導
- 研究論文的統計發現
- 商業廣告的數據宣稱
- 政策決策的統計依據

**作為研究者的統計素養：**
能夠適當地：
- 設計研究以回答問題
- 選擇合適的統計方法
- 正確解釋分析結果
- 誠實報告研究限制

### Unit 2: 研究設計與變項系統


🎯 Unit 2學習目標
- 掌握基本的研究設計原理
- 熟練辨識變項角色和測驗尺度
- 理解實驗設計的邏輯與要素
- 評估研究設計的品質與限制

**2.1 科學研究的基本邏輯 [LSJ Ch.2]**

**研究的起點：好的研究問題**
特徵：
- 具體明確：不是"壓力是否影響健康"，而是"工作壓力是否增加心血管疾病風險"
- 可測量化：概念必須能被操作型定義
- 有理論基礎：建立在既有知識之上
- 實際重要性：有理論或應用價值

**從問題到假設：**
研究問題 → 文獻回顧 → 理論框架 → 具體假設
- 虛無假設（H₀）：沒有效果或關係
- 對立假設（H₁）：有效果或關係

**2.2 變項系統的雙重分類**

**分類維度一：變項角色**

**研究變項（Research Variables）：**
直接與研究假設相關的變項
- **獨立變項（IV）**：研究者操弄或感興趣的預測變項
- **依變項（DV）**：預期被影響的結果變項
- **調節變項（Moderator）**：影響IV和DV關係強度的變項
- **中介變項（Mediator）**：解釋IV如何影響DV的機制變項

**資料變項（Data Variables）：**
提供研究脈絡和品質控制的變項
- **控制變項**：需要保持恆定的變項
- **共變項**：統計控制的變項
- **背景變項**：描述樣本特徵的變項
- **干擾變項**：可能影響結果但未控制的變項

**Zhang研究變項角色分析實例：**

Study 2變項角色識別：

研究變項：
- IV：教學影片類型（Drawing+Hand vs Drawing Only vs Static Slides）
- DV1：後測學習成績（0-17分）
- DV2：學習判斷準確性（-100 to +100）

資料變項：
- 控制變項：前測成績（統計控制原有知識差異）
- 背景變項：年齡、性別、族群（樣本描述）
- 共變項：前測成績（在分析中納入統計控制）


**分類維度二：測驗尺度**

**Level 1: 名目尺度（Nominal Scale）**

特徵：分類無順序
例子：
- 實驗組別：控制組、實驗組A、實驗組B
- 科系：心理系、物理系、化學系
- 治療方法：藥物A、藥物B、安慰劑

jamovi設定：Nominal
適用統計：次數、百分比、眾數、卡方檢定
適用圖表：長條圖、圓餅圖


**Level 2: 順序尺度（Ordinal Scale）**

特徵：可排序但距離不等
例子：
- 教育程度：國小 < 國中 < 高中 < 大學 < 研究所
- 李克特量表：強烈不同意 < 不同意 < 中立 < 同意 < 強烈同意
- 社經地位：低 < 中 < 高

jamovi設定：Ordinal
適用統計：中位數、百分位數、無母數檢定
適用圖表：有序長條圖、累積分布圖


**Level 3: 等距尺度（Interval Scale）**

特徵：距離相等但無絕對零點
例子：
- 溫度（攝氏/華氏）：20°C到30°C的差距 = 30°C到40°C的差距
- 標準化測驗分數：IQ分數、SAT分數
- 日期：2023年到2024年 = 2024年到2025年

jamovi設定：Continuous
適用統計：平均數、標準差、t檢定、相關分析
適用圖表：直方圖、散佈圖、盒鬚圖


**Level 4: 比率尺度（Ratio Scale）**

特徵：距離相等且有絕對零點
例子：
- 身高體重：180公分是90公分的兩倍
- 時間：60分鐘是30分鐘的兩倍
- 反應時間：400毫秒是200毫秒的兩倍
- 年齡：40歲是20歲的兩倍

jamovi設定：Continuous
適用統計：所有統計方法都適用
適用圖表：所有圖表類型都適用


**2.3 實驗設計的核心要素**

**隨機化（Randomization）：**
- **隨機分配**：消除選擇偏誤
- **隨機取樣**：提高外部效度
- **為什麼重要？**：確保各組在已知和未知特徵上都相似

**控制（Control）：**
- **實驗控制**：操弄IV同時控制其他變項
- **統計控制**：用共變項分析控制無法實驗控制的變項
- **對照組設計**：提供比較基準

**複製（Replication）：**
- **直接複製**：使用相同方法重複研究
- **概念複製**：用不同方法檢驗相同假設
- **為什麼重要？**：確保發現的可靠性

**2.4 研究效度評估**

**內部效度（Internal Validity）：**
因果推論的正確性
威脅因子：
- 歷史效應：研究期間發生的外在事件
- 成熟效應：參與者隨時間的自然變化
- 測驗效應：重複測驗造成的學習效果
- 流失效應：參與者中途退出造成的偏誤

**外部效度（External Validity）：**
結果的一般化程度
考量因素：
- 樣本代表性：能否推論到目標母群體
- 情境一般性：能否推論到其他情境
- 時間一般性：能否推論到其他時間點

**構念效度（Construct Validity）：**
測量工具的準確性
評估面向：
- 內容效度：測量工具涵蓋構念的完整性
- 準則效度：與金標準的相關程度
- 區辨效度：與相關但不同構念的區別

### Unit 4: 描述統計量


🎯 Unit 4學習目標
- 掌握集中趨勢測量的概念與應用
- 理解變異性測量的意義與計算
- 學會在jamovi中計算各種描述統計量
- 能根據資料特性選擇適當的描述統計

**4.1 集中趨勢測量 [LSJ Ch.4]**

**什麼是集中趨勢？**
集中趨勢測量告訴我們"資料的中心在哪裡"，是用一個數值來代表整個資料集的典型值。

**平均數（Mean）- 最常用的代表值**

**概念理解：**
平均數是所有數值的總和除以資料個數

公式：μ = Σx / n （母群體平均數）
      x̄ = Σx / n （樣本平均數）

生活例子：
一班10個學生的考試成績：85, 78, 92, 88, 76, 90, 83, 87, 91, 80
平均數 = (85+78+92+88+76+90+83+87+91+80) ÷ 10 = 85分


**jamovi操作：**

1. Analyses → Exploration → Descriptives
2. 將連續變項拖入Variables欄
3. 在Statistics區勾選"Mean"
4. 結果會顯示在右側結果區


**平均數的特性：**
- 包含所有資料點的資訊
- 容易受極端值影響
- 適用於等距和比率尺度資料
- 是推論統計的基礎

**中位數（Median）- 中間位置的代表值**

**概念理解：**
將資料由小到大排列後，位於中間位置的數值

奇數個資料：中間那個數值
偶數個資料：中間兩個數值的平均

例子：考試成績排序後
76, 78, 80, 83, 85, 87, 88, 90, 91, 92
中位數 = (85 + 87) ÷ 2 = 86分


**jamovi操作：**
在Descriptives分析中勾選"Median"

**中位數的特性：**
- 不受極端值影響
- 適用於順序、等距、比率尺度資料
- 當資料有極端值或偏態分布時特別有用
- 容易理解：一半的人高於此值，一半低於此值

**眾數（Mode）- 最常出現的代表值**

**概念理解：**
資料中出現次數最多的數值

例子：一週購物次數
0, 1, 1, 1, 2, 2, 3, 7
眾數 = 1（出現3次，最多）

注意：
- 可能有多個眾數（多峰分布）
- 可能沒有眾數（所有值都只出現一次）


**jamovi操作：**
在Descriptives分析中勾選"Mode"

**眾數的特性：**
- 適用於所有測驗尺度（包括名目尺度）
- 不受極端值影響
- 對於類別資料是唯一合適的集中趨勢測量
- 在市場調查中特別有用

**何時使用哪個集中趨勢測量？**

**平均數適用於：**
- 正常分布的連續資料
- 需要進行進一步統計分析
- 等距或比率尺度資料

**中位數適用於：**
- 偏態分布的資料
- 有極端值的資料
- 順序尺度資料
- 收入、房價等資料

**眾數適用於：**
- 名目尺度資料
- 想知道最常見的類別
- 消費者偏好調查

**4.2 變異性測量**

**為什麼需要變異性測量？**
集中趨勢只告訴我們資料的中心，但不告訴我們資料的散布程度。

**想像兩個班級的平均成績都是80分：**
- A班：78, 79, 80, 81, 82 （成績很集中）
- B班：60, 70, 80, 90, 100 （成績很分散）

雖然平均數相同，但變異性差很多！

**全距（Range）- 最簡單的變異性測量**

**概念理解：**
最大值減去最小值

公式：Range = Max - Min

例子：
A班：82 - 78 = 4分
B班：100 - 60 = 40分


**jamovi操作：**
在Descriptives分析中勾選"Range"

**全距的特性：**
- 容易計算和理解
- 只受極端值影響
- 不考慮中間資料的分布
- 適合初步了解資料散布

**四分位距（IQR）- 穩健的變異性測量**

**概念理解：**
第三四分位數（Q3）減去第一四分位數（Q1）

Q1：25%的資料低於此值
Q3：75%的資料低於此值
IQR = Q3 - Q1


**jamovi操作：**
在Descriptives分析中勾選"Quartiles"

**四分位距的特性：**
- 不受極端值影響
- 描述中間50%資料的散布
- 適合偏態分布
- 常與中位數搭配使用

**變異數（Variance）- 平方偏差的平均**

**概念理解：**
每個資料點與平均數差異的平方和的平均

母群體變異數：σ² = Σ(x - μ)² / N
樣本變異數：s² = Σ(x - x̄)² / (n-1)

為什麼要平方？
- 避免正負偏差相消
- 放大較大的偏差
- 數學處理上的優勢


**jamovi操作：**
在Descriptives分析中勾選"Variance"

**標準差（Standard Deviation）- 最常用的變異性測量**

**概念理解：**
變異數的平方根，回到原始資料的單位

母群體標準差：σ = √σ²
樣本標準差：s = √s²

優點：
- 與原始資料同單位
- 容易解釋
- 統計分析的基礎


**jamovi操作：**
在Descriptives分析中勾選"Standard deviation"

**標準差的解釋規則：**
對於正常分布的資料：
- 約68%的資料在平均數±1個標準差內
- 約95%的資料在平均數±2個標準差內
- 約99.7%的資料在平均數±3個標準差內

**4.3 分布形狀的描述**

**偏態（Skewness）- 資料的對稱性**

**概念理解：**
描述分布偏離對稱的程度

偏態 = 0：完全對稱
偏態 > 0：右偏（正偏），長尾巴在右邊
偏態 < 0：左偏（負偏），長尾巴在左邊

右偏的例子：收入分布（少數人收入很高）

**5.2 標準分數系統**

**Z分數（Standard Score）的概念：**

**什麼是Z分數？**
將原始分數轉換為標準分數，表示該分數距離平均數幾個標準差

公式：z = (x - μ) / σ

解釋：
z = 0：等於平均數
z = 1：高於平均數1個標準差
z = -1：低於平均數1個標準差


**Z分數的應用：**

1. 比較不同測驗的成績：
   數學：85分（M=80, SD=10） → z = 0.5
   英文：78分（M=75, SD=6）  → z = 0.5
   兩科表現相當

2. 識別極端值：
   |z| > 3.29 → 非常極端（p < 0.001）
   |z| > 2.58 → 很極端（p < 0.01）
   |z| > 1.96 → 極端（p < 0.05）


**jamovi中計算Z分數：**

操作步驟：
1. Data → 右鍵 → Add Variable → Computed Variable
2. 命名新變項（如：Z_Score）
3. 輸入公式：(變項名 - VMEAN(變項名)) / VSTDEV(變項名)
4. 新的Z分數變項會自動生成

**5.4 資料品質評估**

**異常值偵測與處理：**

**視覺化偵測方法：**

1. 盒鬚圖（Box Plot）：
   - 超出箱型圖鬍鬚的點為異常值
   - jamovi自動標示異常值

2. 直方圖：
   - 觀察是否有明顯偏離主要分布的數值

3. 散佈圖：
   - 對於雙變項，觀察是否有偏離主要趨勢的點


**數值偵測方法：**

1. Z分數法：
   |z| > 3.29 為極端異常值
   |z| > 2.58 為異常值

2. IQR法：
   Q1 - 1.5×IQR 以下為異常值
   Q3 + 1.5×IQR 以上為異常值

3. 百分位數法：
   低於P5或高於P95可視為異常值


**異常值處理策略：**

1. 檢查資料輸入錯誤：
   - 重新檢視原始資料
   - 確認是否為錄入錯誤

2. 了解異常值成因：
   - 是否為特殊情況？
   - 是否代表真實現象？

3. 處理決策：
   - 保留：如果是真實且有意義的數據
   - 刪除：如果確認為錯誤或不相關
   - 轉換：使用對數轉換等方法
   - 分別分析：單獨分析異常值的影響


**資料分布評估：**

**正常性檢驗：**

視覺方法：
1. 直方圖 + 正常分布曲線
2. Q-Q圖（Quantile-Quantile Plot）
3. 盒鬚圖觀察對稱性

數值方法：
1. 偏態和峰態統計量
2. Shapiro-Wilk檢驗（小樣本）
3. Kolmogorov-Smirnov檢驗（大樣本）


**jamovi中的正常性檢驗：**

操作步驟：
1. Analyses → Exploration → Descriptives
2. 勾選"Shapiro-Wilk"（如果樣本小於50）
3. 在Plots區勾選"Q-Q plots"
4. 觀察結果判斷是否為正常分布

**置信區間的概念：**

95%置信區間：
- 如果重複抽樣100次，95次會包含真正的母群體參數
- 提供參數估計的不確定性資訊
- jamovi可在Descriptives中勾選"Confidence interval"

解釋範例：
平均數 = 14.59, 95% CI [13.32, 15.86]
→ 我們有95%信心真正的母群體平均數在13.32到15.86之間


**效果大小的實務解釋：**

統計顯著性 vs 實務重要性：
- 統計顯著：p < 0.05
- 實務重要：效果大小夠大，有實際應用價值

判斷標準：
- 教育研究：d > 0.4 通常被認為有實務意義
- 心理治療：d > 0.5 被認為有臨床意義
- 需要考慮成本效益和實施可行性

**6.4 圖表解讀與溝通**

**圖表解讀的系統方法：**

**SEES法則：**

Structure（結構）：
- 圖表類型是什麼？
- 變項和尺度是什麼？
- 樣本大小如何？

Extremes（極值）：
- 有異常值嗎？
- 最大值和最小值是多少？
- 極值是否合理？

Patterns（模式）：
- 資料的主要趨勢是什麼？
- 有什麼明顯的模式？
- 組間有差異嗎？

Summary（總結）：
- 主要發現是什麼？
- 與研究假設一致嗎？
- 有什麼實務意涵？


**常見圖表解讀陷阱：**

**誤導性視覺化：**

1. Y軸起點不為零：
   - 誇大小差異的視覺效果
   - 解決：檢查軸的範圍設定

2. 不等間距：
   - 時間軸或數值軸間距不均
   - 解決：確保等距刻度

3. 櫻桃挑選：
   - 只顯示支持特定結論的資料
   - 解決：要求完整資料呈現


**過度解讀：**

1. 因果推論錯誤：
   - 相關不等於因果
   - 需要實驗設計支持因果推論

2. 統計顯著vs實務重要：
   - 大樣本可能產生統計顯著但微小的差異
   - 需要結合效果大小判斷

3. 一般化過度：
   - 樣本特性可能限制推論範圍
   - 需要考慮外部效度
